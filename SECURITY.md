# Security

Report suspected vulnerabilities privately to the repository owner through GitHub's private reporting channel when available.

Never attach or commit local inventory snapshots, SQLite databases, `.pcdbak` files, usernames, absolute user paths, probe output, credentials, passphrases, or other machine-specific data. Update and setup execution require reviewed approval surfaces and exact structured WinGet plans. Temporary cleanup is restricted to the canonical current-user TEMP root; skip links/reparse points and inaccessible or young files, select nothing by default, and revalidate canonical path, parent chain, age, size, timestamp and reparse state immediately before each approved deletion. Backup/restore must include only categories, aliases, assignments, and setup profiles; use the versioned authenticated format, PBKDF2-HMAC-SHA256 at 600,000 iterations, random salt/nonce, AES-256-GCM, strict limits, atomic encrypted writes, a generic wrong-passphrase/tamper error, and an encrypted safety backup before one-transaction restore. Keep expiry, tamper/drift checks, agreement acceptance, partial-result reporting, sequential stop conditions and operation exclusion enforced below the UI; do not introduce plaintext backup files, shell commands, arbitrary paths, unattended changes, automatic retries, rollback claims or automatic reboot.
