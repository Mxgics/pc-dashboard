# Security

Report suspected vulnerabilities privately to the repository owner through GitHub's private reporting channel when available.

Never attach or commit local inventory snapshots, SQLite databases, usernames, absolute user paths, probe output, credentials, or other machine-specific data. Update execution requires the reviewed V2 approval surface and is limited to structured WinGet APIs plus an exact package/source/version/scope plan. Keep plan expiry, tamper/drift checks, agreement acceptance and operation exclusion enforced below the UI; do not introduce shell commands, arbitrary command execution, unattended changes, automatic retries, rollback claims, or automatic reboot.
